# НАСЛЕДНИК — интерактивный сериал для Instagram Reels

2D-анимационная драма: наследник миллиардной империи, загадочная смерть родителей, и каждое решение героя выбирают зрители в комментариях.

## Что здесь
| Путь | Что |
|---|---|
| `episodes/ep01.mp4` | **Готовая серия 1** (47 сек, 1080×1920, со звуком) |
| `story/01_bible.md` | Библия сериала: логлайн, конфликт, мотивация, персонажи |
| `story/02_interactive_system.md` | Как устроены выборы зрителей, очки, формат серии, ритм публикаций |
| `story/03_season1_episodes.md` | План сезона 1: сценарий серии 1, ветки 2A/2B, узлы до финала |
| `video/` | Исходники анимации (всё рисуется кодом) |

## Как сделать новую серию
```bash
cd video
cp -r ep01 ep02                          # новая папка серии
cp audio/ep01_audio.py audio/ep02_audio.py
# правим ep02/scene.js (сцены и титры) и тайминги звука в audio/ep02_audio.py
./build.sh ep02                           # → episodes/ep02.mp4
node render.js ep02 --stills 2,10,20      # быстрые контрольные кадры в video/out/stills
```
Персонажи (Лев, Виктор, Гордеев, Алиса), дождь, титры и карточки выбора лежат в `video/lib/draw.js`, их можно переиспользовать: `person(as('viktor', {x, y, s, mood:'sly'}))`.

Нужны Node.js, ffmpeg, Python 3 + numpy, Playwright (Chromium).
